This is a basic web-based dictionary application built using HTML, CSS, and JavaScript. It allows users to search for any English word and displays its meaning, phonetics, and also provides an option to listen to the pronunciation.

🔍 Features:
Search for English word definitions

Display phonetics (pronunciation guide)

Audio playback to hear how the word is pronounced

Clean and responsive user interface

💻 Technologies Used:
HTML – Structure

CSS – Styling

JavaScript – Functionality and API integration

Free Dictionary API – For fetching word data

🚀 How to Use:
Open index.html in your browser.

Enter a word in the search bar.

View its definition, phonetics, and play the pronunciation.
